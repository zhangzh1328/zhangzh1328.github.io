# Zhenhao Zhang - Academic Homepage

A self-contained academic homepage adapted from [Minimal Light](https://github.com/yaoyao-liu/minimal-light), using its CC0-1.0-licensed styles.

Website: https://zhangzh1328.github.io/

## Updating the page

Edit `index.html` to update the biography, research interests, publications, or academic service. The file includes all styles and the owner-provided avatar and does not require a build system or installed dependencies. Section links, email links, and Google Scholar links are ordinary HTML.

The website supports desktop and mobile layouts, automatic light/dark appearance, keyboard navigation, and printing.

## GitHub Pages

Publish the `main` branch from `/ (root)` under **Settings > Pages**. The `.nojekyll` file allows GitHub Pages to serve the HTML directly.

## Content

Professional information was prepared from the owner-supplied CV, with the current role updated to Incoming PhD Student, University of Macau, as supplied by the owner. Publication years and statuses follow that CV. No phone number or source CV document is bundled with the website.
